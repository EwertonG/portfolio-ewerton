# Portfolio — Ewerton Gomes Barcia

Portfolio pessoal: estudante de Sistemas de Informação (UFOP), foco em desenvolvimento backend e integrações entre sistemas.

## Tecnologias

- [Vite](https://vite.dev/) + TypeScript, sem framework
- CSS puro
- Deploy no GitHub Pages via GitHub Actions

## Como rodar

```bash
npm install
npm run dev       # servidor de desenvolvimento
npm run build     # build de produção em dist/
npm run preview   # serve o build localmente
npm run format    # formata o código com Prettier
```

## Roteiro

| Dia | Branch                      | Entrega                                  |
| --- | --------------------------- | ---------------------------------------- |
| 1   | `chore/estrutura-inicial`   | Estrutura do projeto e ferramentas       |
| 2   | `feat/layout-base`          | Tema, grid, menu lateral e topo          |
| 3   | `feat/sobre-experiencia`    | Dados centralizados, Sobre e Experiência |
| 4   | `feat/projetos-habilidades` | Projetos, Habilidades e Certificações    |
| 5   | `feat/contato-responsivo`   | Contato, rodapé, responsividade e a11y   |
| 6   | `feat/i18n-animacoes`       | Português/inglês e animações             |
| 7   | `chore/deploy-pages`        | SEO e deploy no GitHub Pages             |
